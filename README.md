# 高松灯杯黑客松大赛

## 简要描述

一款主题为数学，计算机，人工智能还有少女乐队有关的活动，参赛者拿着他们的成果去报名，然后进行评选，评分最高的获胜者将会获得“路过参与奖”的称呼和小灯玩偶购买金（金额待定，由获奖者自行购买）。同时，所有参赛者将会获得“第三十六届全国高松灯杯黑客松竞赛冠军”的参与称号。

## 为什么要办这么个比赛

前几天，我做了个MBTI人格测试，发现自己是INFP，和我最喜欢的角色丰川祥子是一样的。

如果说，我对其他角色的喜好有丰川祥子那么高的话，那么对小祥的喜欢足足有高松灯那么高啊。

其实就是都挺喜欢的，因为这两个角色身高都是一米55。

但说句实话，我喜欢的东西还是挺多的，我做的事情就更多了。在每一个不曾起舞的日子里，都是对生命的辜负。而我在没有更新的日子里，也并不是完全辜负了生命，而是也攒出了一些东西。

众所周知，如果不将产品放在真实世界之中进行检验，那么就意味着只是空想。于是我决定喊一堆人过来，看看大家有什么想法，然后再把自己做的内容也放在一起。最终或许能够把所做的东西接收到一个普遍的反馈，并且进而能够见识到更多有意思的想法。

然后，既然这个比赛是在我最喜欢的角色若叶睦的灵感下号召的，所以，就用椎名立希来命名并确定截止时间吧。

于是就有了这么一个高松灯杯的比赛，如果你打算参与，可以直接看下面的**参与方式**把你所做的东西发出来。
